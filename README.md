# Bot Diner

MoneyBot runs a diner, from a roadside shack in Bot County to a flagship in Botropolis. Seat guests, take orders, serve plates, and keep the books: cash, rent, food cost, and upgrades.

The game is one page, `index.html`. Progress is saved in the browser under `botdiner-save`.

## Run

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:47291](http://127.0.0.1:47291).

## Play

Press **Start**. Click a party at the door, then click a table to seat them. Click a table to take the order, click the kitchen window to drop it off, click a finished plate to pick it up, and click the table again to serve and collect. Matching a party to a table of the same color pays a bonus.

After the shift, the day report shows revenue against food cost and rent. Spend what you kept on upgrades, or save it. Grow through four places: The Shack, Bot Diner, Neon Bot Diner, and the Golden Bot Diner.

**M** toggles sound. **P** or **Escape** pauses. On a phone, use the buttons along the bottom.
